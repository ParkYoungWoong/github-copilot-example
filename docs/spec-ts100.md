# TS-100 온도 센서 모듈 스펙

연구개발팀이 개발한 산업용 온도 센서 모듈의 기준 스펙입니다.
값을 바꾸려면 파트장 승인 후 이 문서를 먼저 수정합니다.

## 기본 사양

| 항목 | 값 |
| --- | --- |
| 모델명 | TS-100 |
| 측정 범위 | -40°C ~ 125°C |
| 측정 정확도 | ±0.5°C (-10°C ~ 85°C 구간), ±1.0°C (그 밖의 구간) |
| 분해능 | 0.1°C |
| 샘플링 주기 | 100ms ~ 10s (기본값 1s) |
| 응답 시간 | 2초 이내 (63% 도달 기준) |

## 전기 사양

| 항목 | 값 |
| --- | --- |
| 동작 전압 | 3.3V (허용 범위 3.0V ~ 3.6V) |
| 소비 전류 | 측정 시 12mA, 대기 시 0.8mA |
| 인터페이스 | I2C (기본 주소 0x48), UART (115200bps) |
| 케이블 최대 길이 | I2C 1m, UART 15m |

## 환경 사양

| 항목 | 값 |
| --- | --- |
| 동작 온도 | -40°C ~ 85°C |
| 보관 온도 | -55°C ~ 125°C |
| 방진 방수 | IP67 |
| 인증 | CE, KC |

## 펌웨어

| 항목 | 값 |
| --- | --- |
| 현재 배포 버전 | 2.3.1 (2026-08-28 배포) |
| 안정 버전 | 2.2.4 |
| 업데이트 방식 | UART 부트로더, 사내 포털 배포 파일 사용 |

## 보증

정상 사용 조건에서 출하일로부터 24개월을 보증합니다.
동작 온도 범위를 벗어난 환경에서 발생한 고장은 보증에서 제외됩니다.
