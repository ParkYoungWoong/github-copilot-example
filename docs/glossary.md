# 팀 용어 사전

회의 메모와 이슈에 자주 나오는 팀 용어입니다.
회의록과 보고서에는 오른쪽의 뜻으로 풀어 씁니다.

| 용어 | 뜻 | 주의 |
| --- | --- | --- |
| AI | 액션 아이템(Action Item). 지난 회의에서 담당과 기한을 정한 안건 | 인공지능이 아님 |
| open, close | 진행 중, 완료 | |
| FW | 펌웨어 | |
| RCA | 근본 원인 분석(Root Cause Analysis) | |
| PL | 파트 리더 | 직책이므로 담당으로 쓰지 않음 |
| DV2 | 설계 검증(Design Verification) 2차 샘플 | |
| 챔버 | 환경 챔버 | |
