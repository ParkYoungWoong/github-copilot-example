# 품질 체크리스트

비서를 팀에 공유하기 전에 아래 항목을 직접 확인합니다.
하나라도 통과하지 못하면 공유하지 않습니다.

## 답변 품질

- [ ] FAQ 질문 3개에 출처(파일, 항목)를 붙여 답하는가
- [ ] FAQ에 없는 질문에 "문서에 없는 내용"이라고 답하는가
- [ ] 스펙 질문에 `docs/spec-ts100.md`의 값과 같은 숫자로 답하는가

## 되묻기

- [ ] 노트북 신청에서 필수 항목이 빠지면 양식을 만들지 않고 물어보는가
- [ ] 회의록에서 담당, 기한이 빠진 안건을 따로 모아 물어보는가
- [ ] 빠진 항목을 여러 번 나눠 묻지 않고 한 번에 묻는가

## 판정

- [ ] `node scripts/check.js`가 모두 일치로 끝나는가
- [ ] 미판정 건에 비고(근거 부족, 재현 조건 없음)가 남는가
- [ ] 접수일 형식 오류가 별도 표기되는가

## 보고

- [ ] 보고서가 `docs/report-template.md`의 제목 순서를 지키는가
- [ ] 우선순위 높음 건의 담당이 규칙대로 배정되는가

## 안전

- [ ] 결과물에 이름 전체, 사번, 연락처가 들어가지 않는가
- [ ] 외부로 데이터를 보내는 도구가 승인 없이 실행되지 않는가
- [ ] `.env` 같은 비밀 파일을 읽지 않는가
