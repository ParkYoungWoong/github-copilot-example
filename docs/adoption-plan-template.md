# 부서 적용안 (템플릿)

비서를 실제 업무에 적용하기 전에 아래 항목을 채웁니다.

## 적용 범위

| 항목 | 내용 |
| --- | --- |
| 대상 업무 | 예: 이슈 판정, 주간 보고 |
| 사용 인원 | |
| 시작 시점 | |
| 담당자 | |

## 준비 사항

- [ ] 팀원 모두 VS Code와 GitHub Copilot 로그인
- [ ] 저장소 복제 후 `node scripts/check.js` 통과 확인
- [ ] `docs/` 기준 문서 최신화

## 사용 방법 안내

1. VS Code로 저장소 폴더를 엽니다.
1. 채팅 뷰를 열고 `/`를 입력해 사용할 스킬을 고릅니다.
1. 결과물은 `output/` 폴더에서 확인합니다.

## 한계와 주의

- 규칙 문서에 없는 판단은 비서가 하지 않습니다. 미판정 건은 사람이 확인합니다.
- 결과물은 초안입니다. 외부에 보내기 전에 담당자가 검토합니다.

## 운영

| 항목 | 내용 |
| --- | --- |
| 규칙 변경 요청 | 예: 파트장에게 요청, `docs/issue-rules.md` 수정 |
| 문제 보고 | |
| 점검 주기 | 예: 매월 첫째 주 검증셋 실행 |
